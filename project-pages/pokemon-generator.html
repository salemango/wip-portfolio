Problem

As I'm learning APIs and how to work with them, can I make an app that randomly generates dynamic content from a REST API?

Solution

Using PokéApi, a free, open source, and comprehensive REST API for Pokémon data, I created an app that fetches and displays random Pokémon information on demand. This approach allowed me to understand how to interact with REST APIs and display dynamic content in a web application. Using Vue, I was able to make the site update in real-time as new Pokémon data was fetched. JavaScript logic also supports the random generation aspects by pulling from a list of available numerical Pokémon IDs. The image URLs are pulled from pokemondb.net, which uses a predictable URL structure for their Pokémon images. As my first foray into JSON data, I learned a lot and am excited to keep returning to the techniques displayed here.

Reflection

Creating this Pokémon generator was an excellent way to learn about REST APIs and dynamic content generation with a low-stakes, fun project. It highlighted the importance of understanding JSON data structures and how to manipulate them with JavaScript. The experience of seeing the app update in real-time with new Pokémon information was very rewarding.
