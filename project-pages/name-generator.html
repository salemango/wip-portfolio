Problem

Can I use basic JavaScript to create an app that generates pronounceable, real-sounding names?

Solution

While learning JavaScript, I was quickly fascinated by how easily the language let me implement random generation techniques using basic logic. I realized that, with one array of consonants and one array of vowels, I could randomly generate pronunceable fake words / names by generating a random sequence of characters from these arrays by alternating which array I pulled from for each letter. When I set out to put this to the test, it worked, and I was able to create a simple yet effective name generator.

Reflection

While it's basic and pales in comparison to my more recent projects, I am proud of the foundational skills I developed while creating this name generator. It taught me the basics of JavaScript and how to use arrays and random functions to create dynamic content. It also started a long process of tinkering with random number generation in JavaScript and JavaScript frameworks that continues to this day.
